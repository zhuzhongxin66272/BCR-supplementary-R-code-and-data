# BCR-supplementary-R-code-and-data

Supplementary material (R code and empirical data) for the manuscript *Screening Co-exposure Effects via Basis-Constrained Parameterization: A Dimensionality Reduction Approach*.

## Contents

- `Supplementary_material_BCR_complete_R_code.R` — complete R code for the manuscript: the BCR / WQS / QGCOMP simulation framework (global testing), the formal simulation study, and the NHANES empirical analysis.
- `NHANES2011-2016_4463.xlsx` — the de-identified NHANES 2011–2016 analytic dataset (n = 4,463) used in the empirical analysis.

## Requirements

The R script loads the following packages: `MASS`, `fda`, `glmnet`, `gWQS`, `qgcomp`, `dplyr`.

## Data availability

- **Simulated data**: generated by the deposited code using fixed random seeds documented in the script; every simulated dataset can be regenerated exactly.
- **Empirical data**: the analytic dataset is provided in this repository as `NHANES2011-2016_4463.xlsx`. It is derived from publicly available, de-identified NHANES 2011–2016 data distributed by the National Center for Health Statistics, Centers for Disease Control and Prevention: https://wwwn.cdc.gov/nchs/nhanes/
